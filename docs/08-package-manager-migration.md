# 08 — Package Manager Migration: yarn → pnpm

## Overview

Volto 19 drops yarn support entirely. The Cookieplone-generated project uses pnpm 10 with workspace support. This document covers the key changes.

## package.json changes

### `packageManager` field
```json
{
  "packageManager": "pnpm@10.20.0"
}
```
Corepack uses this to automatically install the correct pnpm version.

### `resolutions` → `pnpm.overrides`

**Current (44 resolutions):**
```json
{
  "resolutions": {
    "@eeacms/volto-eea-kitkat": "33.1.1",
    "react": "18.2.0",
    "react-dom": "18.2.0",
    "react-refresh": "0.14.0",
    ...
  }
}
```

**New (pnpm.overrides):**
```json
{
  "pnpm": {
    "overrides": {
      "@eeacms/volto-eea-kitkat": "33.1.1",
      "react": "18.2.0",
      "react-dom": "18.2.0",
      "react-refresh": "^0.14.2",
      "@pmmmwh/react-refresh-webpack-plugin": "^0.5.15",
      ... (EEA addon pins + React pins)
    },
    "ignoredBuiltDependencies": ["@parcel/watcher"],
    "onlyBuiltDependencies": ["core-js", "cypress", "esbuild", "lightningcss-cli", "unrs-resolver"]
  }
}
```

### What we keep
- **24 EEA addon version pins** — these are our own packages, we control the versions
- **React version pins** (`react`, `react-dom`, `react-is`) — synced with Volto core
- **`react-refresh`** — updated to `^0.14.2` per Volto 19 upgrade guide
- **`@pmmmwh/react-refresh-webpack-plugin`** — `^0.5.15` per Volto 19 upgrade guide

### What we drop
- **Security patches** (`shell-quote`, `sane/execa`, `request/form-data`, `react-error-overlay`, `react-dev-utils`) — likely resolved in Volto 19's updated dependencies. Verify with `pnpm audit` after install.
- **`webpack-bundle-analyzer`** — included in Volto 19 devDependencies
- **`eslint-plugin-jsx-a11y`**, **`eslint-plugin-react-hooks`** — included in Volto 19

## .pnpmfile.cjs

New file (generated by Cookieplone) — pnpm catalog hook:
```js
const fs = require('fs');
const path = require('path');
const catalogPath = path.resolve(__dirname, 'core/catalog.json');
let catalog = {};
if (fs.existsSync(catalogPath)) {
  catalog = JSON.parse(fs.readFileSync(catalogPath, 'utf-8'));
}
module.exports = {
  hooks: {
    updateConfig(config) {
      if (config.catalogs) { config.catalogs.default ??= catalog; }
      return config;
    },
  },
};
```

## Makefile changes

### `develop` target (simplified)
```makefile
# Before (yarn, with workspace protocol hacks)
develop:
    npx -p mrs-developer missdev --config=jsconfig.json --output=addons --fetch-https
    node scripts/apply-workspace-protocol.js
    NODE_OPTIONS="--max-old-space-size=16384" yarn install
    node scripts/restore-production-package.js

# After (pnpm, native workspace)
develop:
    pnpm dlx mrs-developer missdev --config=jsconfig.json --output=packages --fetch-https
    pnpm install
```

### Other targets
```makefile
install:
    pnpm install

build:
    pnpm build

start:
    NODE_OPTIONS="--max-old-space-size=16384" pnpm start

bundlewatch:
    pnpm exec bundlewatch --config .bundlewatch.config.json
```

## Dropped files
- `.yarnrc.yml` — replaced by pnpm
- `.yarn/` directory — replaced by pnpm
- `yarn.lock` — replaced by `pnpm-lock.yaml`
- `scripts/apply-workspace-protocol.js` — pnpm handles workspace natively
- `scripts/restore-production-package.js` — pnpm handles workspace natively
- `jsconfig.json` + `jsconfig.json.prod` — replaced by `tsconfig.json`
- `patches/razzle-jest.patch` — Jest removed in Volto 19
