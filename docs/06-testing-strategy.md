# 06 — Testing Strategy

## Overview

| Pipeline | Unit tests | Acceptance tests |
|---|---|---|
| **Volto 18** (existing) | ❌ Skipped | ✅ Cypress |
| **Volto 19** (new) | ✅ Vitest | ✅ Cypress |

## Why skip unit tests on Volto 18?

Volto 18 uses Jest; Volto 19 uses Vitest. Maintaining both test runners in every addon is unnecessary overhead. Since Cypress acceptance tests provide the primary quality gate, we skip unit tests on the Volto 18 pipeline and rely on Cypress for regression coverage.

## Vitest for Volto 19

Volto 19 removed Jest from core and switched to Vitest. Addons need a `vitest.config.mjs` file. Most existing test files work as-is because Vitest has a Jest-compatible API (`describe`, `it`, `expect`).

### What changes in test files

| Jest API | Vitest equivalent | Action needed |
|---|---|---|
| `describe`, `it`, `expect` | Same | None |
| `jest.fn()` | `vi.fn()` | Conditional or migrate |
| `jest.mock()` | `vi.mock()` | Conditional or migrate |
| `jest.config.js` | `vitest.config.mjs` | Replace config file |

### Vitest config for addons

Generated by the updated `frontend_addon` Cookieplone template:
```js
// vitest.config.mjs
import { defineConfig } from 'vitest/config';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  test: {
    environment: 'jsdom',
    globals: true,
    setupFiles: ['./setup-tests.js'],
  },
});
```

## Cypress for both versions

Cypress remains the cross-version acceptance testing layer. Volto 19 still uses Cypress natively — the Cookieplone templates, Docker images, and Volto core all expect it.

### What stays the same
- Cypress config (`cypress.config.js`)
- Custom Cypress commands
- Test fixtures
- `@testing-library/cypress` integration
- `cypress-axe` for accessibility testing

### What changes
- Cypress tests may need path updates (`src/addons/` → `packages/`) if they reference addon paths directly
- The CI Docker image for Volto 19 testing needs to be a pnpm-based Volto 19 project

## Playwright — deferred

Playwright was considered but deferred:
- Volto 19 still uses Cypress natively
- Migrating to Playwright is a separate project, not part of this upgrade
- All existing Cypress tests, custom commands, and EEA CI infrastructure continue to work
